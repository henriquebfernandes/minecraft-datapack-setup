# Minecraft Java datapack starter

This datapack is set up for Java Edition 26.3.

## Use in a world

Copy this folder into the world's `datapacks` directory, then run `/reload`.
Use `/datapack list` to confirm that Minecraft has loaded it.

## Add commands

- Add commands to `data/example/function/load.mcfunction` to run them on load.
- Add commands to `data/example/function/tick.mcfunction` to run them every tick.
- Use the `example` namespace for additional functions, recipes, loot tables, and other datapack content.
